## Why

当前只能通过文件夹选择器和扫描把素材放入库，用户从 Windows 资源管理器拿到现成素材后，无法直接拖进工作区完成导入。需要增加系统文件拖放入口，同时保留应用内素材卡片拖到侧栏文件夹的既有语义。

## What Changes

- 工作区接受系统文件拖放，悬停时用完整内容区的 2px 蓝色边框和短提示卡反馈投放目标。
- 放下后把文件复制到当前文件夹；当前浏览的是“全部素材”、标签、收藏等非文件夹视图时复制到库根目录。
- 同名文件自动生成 `名称 (2).扩展名` 等唯一名称，不覆盖已有文件；源文件不移动、不删除。
- 只接受格式注册表支持的文件，忽略库内来源、隐藏文件、临时文件、目录和不可读文件，并把跳过数量反馈给用户。
- 继续支持库内素材卡片拖到侧栏文件夹：两类拖拽按 `DataTransfer.types` 分流，互不触发。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `asset-browser`: 工作区 SHALL 支持系统文件拖放导入，并保留既有库内素材拖拽。

## Impact

- 渲染层新增系统文件拖入判定、内容区投放层与对应样式；应用内素材拖拽路径保持不变。
- 主进程新增受限的 `assets:importPaths` IPC 与文件导入服务，复用 `scanPaths`、`upsertScanned`、`withoutRootWatcher` 和缩略图预热。
- 新增主进程导入行为与渲染层拖入判定测试；不改变数据库 schema、不增加依赖。
- 未实现目录递归导入；拖入目录按跳过处理，需后续单独变更。
