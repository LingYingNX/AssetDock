# Spec Delta

## MODIFIED Requirements

### Requirement: 素材卡片
卡片(figure 语义)SHALL 包含:保持原始宽高比的缩略图(悬停不改宽高或位置)、左下类型徽章(深色玻璃小条,视频/三维格式带彩色圆点,映射按规格第 10 节)、右下时长徽章(仅视频)、右上唯一快捷操作收藏(悬停出现)、视频中央播放钮与底部进度条(悬停出现)、三维模型 CSS 转台立方体(六面半透明蓝玻璃 18s 自转 + 底部椭圆投影)、名称一行截断与元信息(分辨率 · 大小;3D 为「面数 · 大小」)。卡片外框圆角 SHALL 比现有卡片令牌小 5px,且 SHALL NOT 显示外部投影;卡片和缩略图 SHALL NOT 因悬停产生位移或缩放。【禁止】卡片缩略图显示中央转台角标、复选圈、快速预览按钮、更多按钮、文件后缀与星级。选中态为蓝描边且不引入外部投影。

#### Scenario: 视频卡片悬停
- **WHEN** 用户悬停视频卡片
- **THEN** 卡片与缩略图位置和尺寸不变,播放钮、进度条和收藏按钮出现;复选圈、快速预览按钮与更多按钮不可见

#### Scenario: 三维卡片悬停
- **WHEN** 用户悬停 GLB 或其他三维素材卡片
- **THEN** CSS 转台立方体继续自转,缩略图中央不出现转台预览角标

#### Scenario: 单击多选
- **WHEN** 用户依次单击两张卡片(均无修饰键)
- **THEN** 前一张取消选中、后一张成为唯一选中项(检查器与键盘焦点随之切换);多选改用 Shift(区间)与 Ctrl/Cmd(逐张)

#### Scenario: Shift 区间选
- **WHEN** 用户先单击卡片 A,再按住 Shift 单击卡片 B
- **THEN** A 到 B(含端点,按当前视图顺序)全部进入选中态并替换此前选区;继续 Shift+单击卡片 C 时区间改为 A 到 C

#### Scenario: Ctrl 逐张切换
- **WHEN** 用户按住 Ctrl(macOS 为 Cmd)单击一张未选中的卡片
- **THEN** 该卡片追加选中且其它卡片保持不变;再次 Ctrl+单击同一卡片则取消该卡选中

#### Scenario: 右键自选中
- **WHEN** 用户在未选中的卡片上点右键
- **THEN** 该卡片成为唯一选中项(检查器切到它)并弹出菜单;在已选中项之一上点右键时保留整组选中不变

#### Scenario: 卡片视觉清理
- **WHEN** 用户浏览任意素材卡片
- **THEN** 卡片外框没有投影,圆角为卡片令牌减 5px,悬停无位移或缩放;除收藏外没有缩略图角标快捷操作

### Requirement: 素材空白区刷选
在素材浏览区的空白处按下鼠标左键并拖拽时,应用 SHALL 显示矩形选框,并把与选框相交的可见素材加入选中;拖拽结束或单击空白处时 SHALL 更新或清空选中。卡片、按钮、输入控件和其他交互元素上的按下操作 SHALL NOT 触发空白区刷选。选中交互在瀑布流、网格、列表与虚拟滚动下 SHALL 保持可用。

#### Scenario: 空白区拖拽选中
- **WHEN** 用户在素材之间的空白处按下左键并拖出经过多张素材的矩形
- **THEN** 应用显示蓝色矩形选框,拖拽结束时所有与矩形相交的可见素材保持选中

#### Scenario: 空白单击清空
- **WHEN** 用户在素材浏览区空白处单击左键
- **THEN** 当前素材选中状态清空,且不打开任何素材

#### Scenario: 卡片操作不误触
- **WHEN** 用户在素材卡片或其收藏按钮上按下鼠标左键
- **THEN** 应用不启动空白区矩形选框;卡片单击为单选、双击打开预览、右键先选中再弹菜单,三者互不干扰
