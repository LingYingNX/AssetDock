# Spec Delta

## MODIFIED Requirements

### Requirement: 右键菜单
在素材上右键 SHALL 弹出菜单:在资源管理器中显示 / ─ / 重命名 `F2` / 移动到… › / 添加标签… › / 添加到收藏 / 复制 `Ctrl C` / 导出… / ─ / 文件信息 `Ctrl I` / ─ / 删除 `Del`(红色,悬停 --danger-soft)。菜单跟随光标,靠近屏幕边缘时防溢出翻转。弹出前 SHALL 先把被右键的素材设为唯一选中(该素材已在当前选区内时 SHALL 保留整组选中不变),菜单操作范围与选中集保持一致。

#### Scenario: 屏边防溢出
- **WHEN** 用户在贴近窗口右下角的卡片上右键
- **THEN** 菜单完整显示在窗口内(向左/向上翻转),不被裁切

#### Scenario: 右键选中后弹菜单
- **WHEN** 用户在一张未选中的卡片上右键
- **THEN** 该卡片先进入选中态、检查器切到它,随后菜单弹出

#### Scenario: 在多选之一上右键
- **WHEN** 用户已选中多张卡片,在其中一张上右键
- **THEN** 整组选中保持不变,菜单操作作用于整组

### Requirement: 全局键盘快捷键
应用 SHALL 支持:Ctrl F 聚焦搜索、Enter 打开预览、Space 将焦点卡片设为唯一选中、Esc 关闭灯箱与菜单、←/→ 灯箱切换、F2 重命名(进入检查器文件名编辑)、Ctrl I 文件信息(打开灯箱信息)、Del 删除选中素材(移入回收站)、Ctrl 滚轮缩放缩略图。

#### Scenario: Ctrl 滚轮缩放
- **WHEN** 光标位于素材网格上,用户按住 Ctrl 滚动滚轮
- **THEN** 缩略图列宽在 170–320px 范围内变化,效果与拖动缩放滑块一致

#### Scenario: Space 单选焦点卡片
- **WHEN** 用户按下 Space
- **THEN** 当前焦点卡片成为唯一选中项,不再因已选中而被取消
