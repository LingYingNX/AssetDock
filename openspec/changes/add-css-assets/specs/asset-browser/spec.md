# Spec Delta

## MODIFIED Requirements

### Requirement: 筛选条
筛选条(42px)SHALL 从左到右包含:颜色构造按钮(彩虹圆球,展开时蓝描边)、五个筛选下拉按钮(格式/形状/尺寸/评分/标签,内容按规格;有激活筛选的按钮呈 .on 蓝底蓝字)、结果统计(「筛选结果 N 项 · 大小」,数字加粗)、视图下拉(图标随视图切换)、竖分隔线、缩放滑块(88×3px 轨道,拖动实时改 --colw 170–320px 并刷新填充比例)、面板开关(隐藏检查器时按钮进入 .on 态)。格式下拉 SHALL 含「CSS」项,选中后仅显示 CSS 素材;形状、尺寸、评分筛选对 CSS 素材 SHALL 按无尺寸素材的既有语义处理,不得使 CSS 素材在该筛选下意外全部消失或全部出现。

#### Scenario: 拖动缩放滑块
- **WHEN** 用户拖动缩放滑块
- **THEN** 素材缩略图列宽在 170–320px 间实时变化,轨道蓝填充比例同步刷新

#### Scenario: 按 CSS 格式筛选
- **WHEN** 用户在格式下拉选择「CSS」
- **THEN** 结果统计与网格只保留 CSS 素材,其它格式不出现在该视图中

### Requirement: 素材卡片
卡片(figure 语义)SHALL 包含:保持原始宽高比的缩略图(悬停不改宽高或位置)、左下类型徽章(深色玻璃小条,视频/三维格式带彩色圆点,映射按规格第 10 节)、右下时长徽章(仅视频)、右上唯一快捷操作收藏(悬停出现)、视频中央播放钮与底部进度条(悬停出现)、三维模型 CSS 转台立方体(六面半透明蓝玻璃 18s 自转 + 底部椭圆投影)、名称一行截断与元信息(分辨率 · 大小;3D 为「面数 · 大小」)。CSS 素材卡片 SHALL 显示其渲染效果缩略图与 CSS 类型徽章,元信息 SHALL 只显示大小。卡片外框圆角 SHALL 比现有卡片令牌小 5px,且 SHALL NOT 显示外部投影;卡片和缩略图 SHALL NOT 因悬停产生位移或缩放。【禁止】卡片缩略图显示中央转台角标、复选圈、快速预览按钮、更多按钮、文件后缀与星级。选中态为蓝描边且不引入外部投影。

#### Scenario: 视频卡片悬停
- **WHEN** 用户悬停视频卡片
- **THEN** 卡片与缩略图位置和尺寸不变,播放钮、进度条和收藏按钮出现;复选圈、快速预览按钮与更多按钮不可见

#### Scenario: 三维卡片悬停
- **WHEN** 用户悬停 GLB 或其他三维素材卡片
- **THEN** CSS 转台立方体继续自转,缩略图中央不出现转台预览角标

#### Scenario: CSS 卡片显示渲染缩略图
- **WHEN** 用户浏览含 CSS 素材的文件夹
- **THEN** CSS 卡片显示该样式渲染效果的缩略图与 CSS 徽章,元信息只显示大小,不出现分辨率占位

#### Scenario: 单击多选
- **WHEN** 用户依次单击两张卡片
- **THEN** 两张卡片均进入选中态(蓝描边),多选累加;再次单击已选卡片则取消该卡选中

#### Scenario: 卡片视觉清理
- **WHEN** 用户浏览任意素材卡片
- **THEN** 卡片外框没有投影,圆角为卡片令牌减 5px,悬停无位移或缩放;除收藏外没有缩略图角标快捷操作
