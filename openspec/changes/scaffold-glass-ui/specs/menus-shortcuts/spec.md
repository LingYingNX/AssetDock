## Purpose

下拉菜单、右键菜单与全局键盘快捷键,统一玻璃菜单视觉与单选互斥规则。

## ADDED Requirements

### Requirement: 下拉菜单
筛选按钮与视图按钮的菜单 SHALL 定位到按钮下方右对齐,使用玻璃配方(圆角 16、min-width 196);条目 12.5px、行高约 30、圆角 6,悬停 --acc-soft;单选组内互斥,选中项左侧蓝色 ✓;右侧可带键帽或次要说明。触发按钮在菜单有选中项时呈 .on 态。

#### Scenario: 格式筛选互斥
- **WHEN** 用户在格式菜单中先后选择「图片」和「视频」
- **THEN** ✓ 移到「视频」,「图片」取消,格式按钮保持 .on 态

#### Scenario: 关闭菜单
- **WHEN** 菜单打开时用户点击菜单外任意位置或按 Esc
- **THEN** 菜单关闭

### Requirement: 右键菜单
在素材上右键 SHALL 弹出菜单:打开预览 `Enter` / 在资源管理器中显示 / ─ / 重命名 `F2` / 移动到… › / 添加标签… › / 添加到收藏 / 复制 `Ctrl C` / 导出… / ─ / 文件信息 `Ctrl I` / ─ / 删除 `Del`(红色,悬停 --danger-soft)。菜单跟随光标,靠近屏幕边缘时防溢出翻转。

#### Scenario: 屏边防溢出
- **WHEN** 用户在贴近窗口右下角的卡片上右键
- **THEN** 菜单完整显示在窗口内(向左/向上翻转),不被裁切

### Requirement: 全局键盘快捷键
应用 SHALL 支持:Ctrl F 聚焦搜索、Enter 打开预览、Space 选中/取消焦点卡片、Esc 关闭灯箱与菜单、←/→ 灯箱切换、F2 重命名(进入检查器文件名编辑)、Ctrl I 文件信息(打开灯箱信息)、Del 删除选中素材(移入回收站)、Ctrl 滚轮缩放缩略图。

#### Scenario: Ctrl 滚轮缩放
- **WHEN** 光标位于素材网格上,用户按住 Ctrl 滚动滚轮
- **THEN** 缩略图列宽在 170–320px 范围内变化,效果与拖动缩放滑块一致
