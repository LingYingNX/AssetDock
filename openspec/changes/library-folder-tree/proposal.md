## Why

库模式侧栏目前从已入库素材的相对路径构建文件夹树，会把索引源和陈旧数据库路径误显示为库内目录，也无法显示空文件夹。启动状态还保留了两个硬编码示例库标签与示例素材，已绑定真实库时仍可能显示不属于用户的数据。用户需要像 Windows 资源管理器一样，只看到当前真实素材库的内容，并在其中直接新建和重命名真实文件夹。

## What Changes

- 库模式“文件夹”树改为读取当前素材库根目录的真实目录层级，显示空目录并排除 `.mediahub`；外部索引源不混入此树，但在独立只读的“索引目录”树中显示来源名称及其源目录层级，并支持按来源或源目录筛选网格。
- 启动时仅从已绑定库和持久化标签恢复会话；存在已绑定库但没有有效持久化标签时，自动打开第一个真实库，绝不显示硬编码示例库或示例素材。
- 在“文件夹”标题右侧提供图标加号；点击后在库根创建唯一的 `未命名` 目录，并立即选中进入内联改名。
- 内联改名在确认时重命名磁盘目录；选中文件夹按 F2 也能进入同一内联编辑；重名或非法名称显示失败结果且不改变现有目录。
- 库内真实素材和外部索引素材卡片支持拖到侧栏真实文件夹；目标文件夹放下后显示「移动 N / 归类 N / 取消」确认按钮，确认后库内素材移动磁盘文件并同步 `rel_path`，索引素材只同步 `folder_path`。
- 文件夹新增、删除和重命名后刷新目录树，使应用内操作与资源管理器中的目录变动保持一致。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `asset-browser`: 库模式文件夹树改为真实文件系统目录树，并新增在库根创建、F2 内联重命名文件夹，以及库内素材移动和索引素材归类的交互。

## Impact

- 影响 `src/main/ipc.ts`、预加载桥接、库模式 UI 状态、应用启动恢复、侧栏组件和侧栏样式。
- 新增主进程文件系统目录枚举与安全的创建/重命名 IPC，复用既有忽略规则和文件监听；索引素材归类只使用既有 `folder_path` 字段。
- 新增针对目录树、`.mediahub` 排除、新建命名冲突、重命名校验、安全素材移动和索引重扫保留归属的测试；不新增依赖，不迁移数据库。
