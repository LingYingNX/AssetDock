# Spec Delta

## MODIFIED Requirements

### Requirement: 三视图切换
素材网格 SHALL 支持三种视图:瀑布流(默认,CSS 多列 column-width:var(--colw))、网格(repeat(auto-fill,minmax(var(--colw),1fr)),缩略图统一 4:3)、列表(单列行,列网格 96px|1.7fr|52px|92px|76px|60px|96px|34px,含粘性表头,行悬停玻璃底,无评分列)。视图下拉切换时容器类与按钮图标同步切换。瀑布流 SHALL 是唯一使用素材展示比例的视图:其列内定位高度 SHALL 与卡片实际渲染比例同源(同一 `thumbRatio` 求值),SHALL NOT 在估算侧与渲染侧各做一份比例计算;网格视图缩略图统一 4:3,列表视图固定 96x58,两者 SHALL NOT 受素材原始比例影响。

#### Scenario: 切换到列表视图
- **WHEN** 用户在视图下拉中选择「列表」
- **THEN** 网格切换为单列行布局并显示表头(缩略图/文件名/类型/分辨率/大小/时长/导入时间/操作),按钮图标变为列表图标

#### Scenario: 瀑布流列内定位与卡片一致
- **WHEN** 瀑布流中含极端宽高比素材且素材总数超过 500 项(启用虚拟化)
- **THEN** 同列卡片按序紧密排列,相邻卡间隙在几像素内,不出现卡片重叠或列底空档

### Requirement: 素材卡片
卡片(figure 语义)SHALL 包含:缩略图、左下类型徽章(深色玻璃小条,视频/三维格式带彩色圆点,映射按规格第 10 节)、右下时长徽章(仅视频)、右上唯一快捷操作收藏(悬停出现)、视频中央播放钮与底部进度条(悬停出现)、三维模型 CSS 转台立方体(六面半透明蓝玻璃 18s 自转 + 底部椭圆投影)、名称一行截断与元信息(分辨率  大小;3D 为「面数  大小」)。缩略图 SHALL 按素材比例展示,比例收敛到 `[1/2, 21/9]`(`MIN_THUMB_AR` 与 `MAX_THUMB_AR`):界内比例如实展示,超出部分交给 `object-fit:cover` 居中裁切,无尺寸素材按 4:3 兜底。缩略图 SHALL NOT 因悬停改变宽高或位置。元信息行 SHALL 使用二级文本色 `--t2`,网格与列表两种视图取值一致。收藏按钮 SHALL 在夜间主题下满足 WCAG AA:白图标对按钮底对比度  4.5:1;已收藏态 SHALL 同时以实心图标与更深底色表达,SHALL NOT 仅依靠颜色区分状态。卡片外框圆角 SHALL 比现有卡片令牌小 5px,且 SHALL NOT 显示外部投影;卡片和缩略图 SHALL NOT 因悬停产生位移或缩放。【禁止】卡片缩略图显示中央转台角标、复选圈、快速预览按钮、更多按钮、文件后缀与星级。选中态为蓝描边且不引入外部投影。

#### Scenario: 视频卡片悬停
- **WHEN** 用户悬停视频卡片
- **THEN** 卡片与缩略图位置和尺寸不变,播放钮、进度条和收藏按钮出现;复选圈、快速预览按钮与更多按钮不可见

#### Scenario: 三维卡片悬停
- **WHEN** 用户悬停 GLB 或其他三维素材卡片
- **THEN** CSS 转台立方体继续自转,缩略图中央不出现转台预览角标

#### Scenario: 单击多选
- **WHEN** 用户依次单击两张卡片(均无修饰键)
- **THEN** 前一张取消选中、后一张成为唯一选中项(检查器与键盘焦点随之切换);多选改用 Shift(区间)与 Ctrl/Cmd(逐张)

#### Scenario: Shift 区间选
- **WHEN** 用户先单击卡片 A,再按住 Shift 单击卡片 B
- **THEN** A 到 B(含端点,按当前视图顺序)全部进入选中态并替换此前选区;继续 Shift+单击卡片 C 时区间改为 A 到 C

#### Scenario: Ctrl 逐张切换
- **WHEN** 用户按住 Ctrl(macOS 为 Cmd)单击一张未选中的卡片
- **THEN** 该卡片追加选中且其它卡片保持不变;再次 Ctrl+单击同一卡片则取消该卡选中

#### Scenario: 右键自选中
- **WHEN** 用户在未选中的卡片上点右键
- **THEN** 该卡片成为唯一选中项(检查器切到它)并弹出菜单;在已选中项之一上点右键时保留整组选中不变

#### Scenario: CSS 卡片显示渲染缩略图
- **WHEN** 用户浏览含 CSS 素材的文件夹
- **THEN** CSS 卡片显示该样式渲染效果的缩略图与 CSS 徽章,元信息只显示大小,不出现分辨率占位

#### Scenario: 极端比例缩略图收敛
- **WHEN** 用户浏览一张 1200x172(约 7:1)的视频素材卡片
- **THEN** 缩略图按 21:9 展示(232px 列宽下高度不低于 90px),不再塌成一条横线;瀑布流列内占位与卡片实际高度一致,同列卡片不重叠

#### Scenario: 竖屏素材不被误裁
- **WHEN** 用户浏览一张 9:16 的竖屏素材(比例 0.5625)
- **THEN** 缩略图完整按 0.5625 展示,不触发裁切;超过下界 1/2 的更瘦截图才按 1/2 裁切

#### Scenario: 收藏状态双通道可辨
- **WHEN** 用户在夜间主题下把一张卡片加入收藏(悬停揭示收藏按钮)
- **THEN** 按钮底色加深、图标由描边变为实心,白图标对比度不低于 4.5:1、已收藏粉心不低于 3:1,在灰度下也能分辨两种状态

#### Scenario: 卡片视觉清理
- **WHEN** 用户浏览任意素材卡片
- **THEN** 卡片外框没有投影,圆角为卡片令牌减 5px,悬停无位移或缩放;除收藏外没有缩略图角标快捷操作
