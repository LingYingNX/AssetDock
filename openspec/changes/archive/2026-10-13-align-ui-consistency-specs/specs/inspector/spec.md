# Spec Delta

## MODIFIED Requirements

### Requirement: 面板结构与内容
检查器 SHALL 自上而下按分块结构渲染:颜色构造(无标题,5 个 42px 高色块横排,显示占比 + 色值白字深投影,悬停上浮 2px,仅图片素材显示)、文件名块(13px 600 一行截断 + 编辑铅笔图标)、评分与状态块(16px 可点金星 +「⚑ 待审」描边按钮,悬停变 --warn)、文件信息块(两列 dl,64px 标签列;图片/视频显示类型/分辨率/时长/大小/导入/来源,三维显示类型(GLB glTF 2.0)/面数/顶点/材质(PBR·套数·贴图规格)/大小/导入)、标签胶囊区(高 23px 圆角 11 白玻璃 chip,彩点 + 删除 ×)、输入框(高 28,placeholder「输入标签，Enter 添加」+ Enter 键帽)、推荐标签虚线胶囊、来源链接输入框(带链接图标)、备注多行文本域(min-height 56px)。【禁止】所属文件夹区块、预览播放器、面板页签。

间距 SHALL 以「分块」为单位表达,SHALL NOT 理解为自上而下处处等差 16px:同一块内的同级元素保持 16px 间距;块与块之间由标题与分隔线界定。首块(颜色构造/文件名)SHALL 承担面板标题角色——其下 SHALL 有一条 `--sep` 分隔线,把「文件名 + 编辑铅笔 + 待审按钮 + 星级」这一组同类信息与后续块分开;其余块(评分与状态、文件信息、标签、来源链接、备注)SHALL 各自带 `.insp-h` 标题(11px、`--t3`、带图标)。这样「文件名 + ✎ + 待审 + 星级」不会再与相邻语义块混作一行而看起来像两个碰巧挨着的控件。

#### Scenario: 查看三维素材
- **WHEN** 用户选中一个 GLB 素材
- **THEN** 检查器文件信息显示 3D 字段组(类型 GLB glTF 2.0、面数千分位、顶点、材质、大小、导入),不显示分辨率/时长

#### Scenario: 首块与后续块以分隔线分界
- **WHEN** 用户选中任意素材打开检查器
- **THEN** 文件名块下方有一条 `--sep` 分隔线,评分与状态、文件信息、标签、来源链接、备注各块均带 `.insp-h` 标题,块与块之间不靠等差 16px 也能看出分组

#### Scenario: 标签输入框占位文本标点
- **WHEN** 用户查看标签输入框的占位文本
- **THEN** 显示为「输入标签，Enter 添加」,逗号为全角,与界面其余中文标点一致
