# Spec Delta

## Purpose

让从外部站点收集来的 CSS 片段作为一等素材进入素材库：可在管理器内识别、查看渲染效果、像记事本一样编辑并保存回写原文件。

## ADDED Requirements

### Requirement: CSS 素材识别与展示

库内 `.css` 文件 SHALL 作为素材类型 `style`、格式 `CSS` 入库，扫描与监听的大小写不敏感；该类型 SHALL NOT 采集宽高、时长或主色，检查器与卡片 SHALL NOT 显示分辨率行。CSS 素材 SHALL 参与既有的文件夹、标签、评分、收藏、搜索、回收站与缺失文件语义，行为与其它素材一致。

#### Scenario: 放入 CSS 文件后出现在网格
- **WHEN** 向库目录（含子目录）放入一个 `.css` 文件
- **THEN** 数秒内网格出现该素材，类型徽章显示 CSS，名称不含扩展名

#### Scenario: 不是图片
- **WHEN** 查看 CSS 素材的检查器文件信息
- **THEN** 只显示类型、大小、导入时间与来源，不显示分辨率、时长或主色色带

### Requirement: CSS 缩略图

CSS 素材 SHALL 与位图共用 `<库>/.mediahub/thumbs/` 缩略图缓存（640px 长边 JPG、指纹命名、`index.json` 清单、随原图移动与删除的既有语义）。缩略图内容 SHALL 由该 CSS 文件与其预览骨架离屏渲染后截图得到，而非文本占位图；渲染 SHALL NOT 阻塞主进程窗口或素材网格。生成失败（渲染超时、文件损坏）时 SHALL 退回 CSS 格式占位图而非中断网格。

#### Scenario: 首次浏览含 CSS 的文件夹
- **WHEN** 用户浏览一个含 CSS 素材的文件夹
- **THEN** 卡片显示该 CSS 实际渲染效果的缩略图，而非空白或纯文本占位

#### Scenario: 编辑 CSS 后缩略图更新
- **WHEN** 用户在编辑器中修改并保存某 CSS 文件
- **THEN** 其缩略图按新内容重新生成，卡片显示更新后的效果

### Requirement: CSS 灯箱编辑器

双击 CSS 卡片 SHALL 打开专用编辑视图：左侧为可编辑的代码区域（显示该 CSS 文件的原始文本，保留缩进与换行），右侧为实时预览区域。代码修改 SHALL 在短暂防抖后刷新预览，无需手动操作。编辑器 SHALL 提供保存动作与 `Ctrl+S` 快捷键，保存 SHALL 把当前文本写回原 `.css` 文件。预览 SHALL 使用当前编辑器内容（含未保存修改），而非磁盘上的旧内容。

#### Scenario: 打开并编辑
- **WHEN** 用户双击库内 CSS 卡片，在左侧代码区修改一条颜色声明
- **THEN** 右侧预览在短暂延迟后反映新颜色，左侧内容与文件磁盘内容此时可不一致

#### Scenario: 保存回写原文件
- **WHEN** 用户在编辑器中按 `Ctrl+S` 或点击保存
- **THEN** 原 `.css` 文件内容被更新为编辑器中的文本，界面提示保存成功

### Requirement: 预览骨架与作用域

预览 SHALL 由一个 HTML 骨架承载目标 CSS：CSS 同目录存在同名 `.html` / `.htm`（例如 `loader.css` → `loader.html`）时 SHALL 使用该骨架，否则 SHALL 使用应用内置的通用演示骨架，包含标题、按钮、输入框、卡片、列表与加载器等等待常见元素以命中典型选择器。预览 SHALL 在沙箱 iframe 内渲染，骨架中的 `<script>` SHALL 被剥离，外部网络请求 SHALL 被阻止；预览只 SHALL 读取当前素材库内的文件。

#### Scenario: 使用同名 HTML 骨架
- **WHEN** 用户打开 `loader.css` 且同目录存在 `loader.html`
- **THEN** 预览使用 `loader.html` 的结构，而不是内置骨架

#### Scenario: 骨架缺省回退
- **WHEN** 用户打开一个没有同名 HTML 的 CSS 素材，其规则命中按钮或输入框
- **THEN** 内置骨架提供对应元素，预览显示出该规则的效果

#### Scenario: 脚本与外部资源被拦
- **WHEN** 预览骨架中含有 `<script>` 或指向外部站点的资源
- **THEN** 脚本不执行，外部请求不发生

### Requirement: 未保存改动的保护

编辑器 SHALL 跟踪自上次保存以来的未保存状态并在界面上可见地标注。存在未保存改动时，用户关闭编辑器（Esc、关闭按钮或切换素材）SHALL 先要求确认，取消 SHALL 保持编辑器与改动不丢失；确认丢弃后 SHALL 恢复为文件当前内容。保存失败（文件缺失、只读、IO 错误）SHALL 显示失败原因并保留编辑器内容。

#### Scenario: 有改动时关闭
- **WHEN** 用户修改代码后按 Esc 或点击关闭
- **THEN** 出现放弃改动的确认，取消后编辑器与原改动仍在

#### Scenario: 保存失败
- **WHEN** 保存时原文件已被删除或不可写
- **THEN** 界面提示失败原因，编辑器内的改动不丢失

### Requirement: 保存的数据一致性

保存 SHALL 经库根路径校验后写入，SHALL NOT 允许写库目录之外的文件，也 SHALL NOT 允许通过符号链接或 Junction 越界写入；写入 SHALL 采用先写临时文件再原子替换的方式，避免中断留下半截文件。保存成功后 SHALL 更新该素材的内容指纹与大小，使缓存与缩略图按新内容刷新；保存 SHALL NOT 改动素材 id、标签、评分、文件夹归属或导入时间。

#### Scenario: 保存后元数据同步
- **WHEN** 用户保存一次 CSS 修改
- **THEN** 素材 id 与标签/评分不变，大小与指纹更新，卡片缩略图重新生成

#### Scenario: 越界写入被拒
- **WHEN** 请求写入的路径经符号链接指向库目录之外
- **THEN** 写入被拒绝，目标文件不被修改
