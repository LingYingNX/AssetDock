## Context

标题栏由无边框窗口的拖拽区、库标签页、「+」按钮和窗口控制组成。现有下拉组件被筛选器复用,不能全局改小。

## Goals

- 保持下拉组件的通用能力,只给标题栏菜单启用紧凑形态。
- 右键索引明确归属被右键的标签页,而不是激活标签页的隐式状态。
- 弹窗打开时让标题栏可接收 pointer 事件;关闭后恢复系统拖拽。

## Approach

- `Dropdown` 增加 `compact` 形态:宽度按内容收缩,按钮和图标降低密度;无选中值时不渲染勾选占位。
- 「+」菜单只保留新建命令;已打开标签页挂 `tab-<id>` 菜单,右键打开。
- 菜单打开时通过 inline `WebkitAppRegion: no-drag` 覆盖标题栏与标签区默认拖拽;全局捕获 pointerdown 负责外点关闭。
- 点击右键菜单项先 `openTab(t.id)` 再调用 `indexFlow()`,使索引流程读取正确库。

## Trade-offs

- 菜单打开期间标题栏不能拖拽;这是让点击关闭菜单生效的必要切换,关闭后立即恢复。
- 迁移残留清理仍保留 IPC,但暂时没有常规 UI 入口。
