## ADDED Requirements

### Requirement: 文件夹右键菜单

素材管理侧栏中每个真实文件夹行 SHALL 提供右键菜单，按顺序包含“新增子文件夹、移动、重命名、源目录、删除”。菜单 SHALL 跟随光标并防屏边溢出，使用图标槽与组间分隔；“移动”SHALL 用右侧子菜单列出合法目标。按 Esc、点击菜单外或在已打开菜单时右击另一文件夹，SHALL 关闭或原位重建菜单，不得要求先关闭再右键。

#### Scenario: 打开文件夹菜单
- **WHEN** 用户在一个真实文件夹行上点击右键
- **THEN** 该文件夹的菜单在光标处展开，五项动作按规定顺序可见，且素材右键菜单不会同时显示

#### Scenario: 新增子文件夹并原地命名
- **WHEN** 用户选择“新增子文件夹”
- **THEN** 新目录创建在目标文件夹内，父目录自动展开，新节点被选中并立即显示全选的内联名称输入框

#### Scenario: 移动到合法父级
- **WHEN** 用户展开“移动”子菜单
- **THEN** 子菜单只列出库根和目标文件夹，排除源文件夹自身、其后代及当前父目录；选择目标后复用既有文件夹移动链路并回读磁盘状态

#### Scenario: 重命名与打开源目录
- **WHEN** 用户选择“重命名”或“源目录”
- **THEN** “重命名”进入现有原地全选编辑，“源目录”经主进程库内路径校验后由系统文件管理器打开该目录

#### Scenario: 删除到系统回收站
- **WHEN** 用户选择“删除”并在确认中继续
- **THEN** 整棵目录先移入系统回收站；移动成功后素材库才移除该目录下的资产索引、标签关联、排序与派生缓存，文件不得被永久删除

#### Scenario: 取消或失败不破坏索引
- **WHEN** 用户取消删除确认，或目录移入回收站失败
- **THEN** 数据库、素材索引与目录树保持不变，并显示可理解的失败结果

#### Scenario: 减少动态与屏边定位
- **WHEN** 系统启用“减少动态效果”，或用户在贴近窗口边缘的文件夹上右键
- **THEN** 菜单不播放位移或缩放动画，完整落在视口内且所有动作仍可操作
