# Proposal

## Why

左侧素材管理树的文件夹目前只能通过顶栏新建、拖拽和 F2 操作。用户缺少一个集中入口来完成当前文件夹相关的文件管理动作，也无法直接定位到源目录或以安全方式移除整棵目录。

## What Changes

- 为素材库中的真实文件夹行增加右键菜单，顺序为“新增子文件夹、移动、重命名、源目录、删除”。
- 新增子文件夹创建在目标文件夹内；创建成功后展开父目录、选中新节点并立即进入全选内联重命名。
- “移动”使用层级子菜单列出合法目标，过滤自身、后代和当前父目录，复用现有文件夹移动事务。
- “源目录”经主进程校验后调用系统文件管理器打开真实目录。
- “删除”先显示后果确认，再把整棵目录移入系统回收站；只有移入成功后，才以事务清理资产索引、标签关联和文件夹排序，并清理派生缩略图与文档预览缓存。
- 菜单沿用项目液态玻璃表面和设计令牌，同时采用 Uiverse 分组列表组件的图标槽、组间分隔、悬停微位移与危险项独立着色。

## Capabilities

### Modified Capabilities

- `menus-shortcuts`: 增加文件夹行右键菜单的入口、分组、层级移动子菜单、关闭规则与五项动作。

## Impact

- 渲染层：`Sidebar.tsx`、新增 `FolderContextMenu.tsx`、`store/ui.ts`、`App.tsx`、`styles/menu.css`。
- 主进程：`ipc/assets.ts`、`services/folders.ts`、`services/store.ts`。
- 预加载桥：`preload/index.ts` 增加创建子目录、打开源目录与移入回收站能力。
- 测试：`tests/folders.test.ts` 覆盖嵌套创建、路径边界与目录树索引清理。
- 数据：删除只清理移入回收站目录下的库内索引与派生缓存，不永久删除文件，不接触库外路径。
