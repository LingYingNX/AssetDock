# Spec Delta

## ADDED Requirements

### Requirement: 文档扫描与监听

扫描、文件监听与拖入导入 SHALL 从同一格式能力注册表接受文档扩展名。新增、修改、删除或恢复文档时，素材记录 SHALL 与现有图片、视频和三维素材走相同的增量更新、缺失标记与回收站语义。

#### Scenario: 新文档自动入库

- **WHEN** 向已监听库复制一个 `report.docx`
- **THEN** 数秒内出现文档素材卡片，不需要重启应用或手动重新扫描

#### Scenario: 文档被修改

- **WHEN** 库内 XLSX 文件内容变化并产生新指纹
- **THEN** 素材记录更新大小、mtime 与指纹，旧缩略图和旧预览状态失效

#### Scenario: 文档被删除

- **WHEN** 从磁盘删除一个 PPTX 文件
- **THEN** 对应素材标记为缺失并从默认视图消失，数据库中的标签与备注保留

#### Scenario: 拖入文档

- **WHEN** 用户把系统文件夹中的 TXT、Markdown 或 DOCX 拖入当前库
- **THEN** 文件复制到目标文件夹并作为文档素材入库，不覆盖同名文件

### Requirement: 文档扫描元数据

扫描文档时 SHALL 尽力读取页数、工作表数、幻灯片数、列数、行数或文本编码等可用信息，并 SHALL NOT 为读取元数据执行宏、脚本或外部网络请求。无法可靠读取时 SHALL 留空对应字段并照常入库。

#### Scenario: XLSX 工作表数量

- **WHEN** 扫描含三个工作表的 XLSX
- **THEN** 素材元数据记录工作表数量，检查器可显示该信息

#### Scenario: 元数据读取失败

- **WHEN** 文档损坏或加密导致元数据无法读取
- **THEN** 文档仍获得基础素材记录，解析失败在预览阶段给出具体原因
